# 诡镇奇谈 AHLCG（Python 实现）

《Arkham Horror: The Card Game》基础包《狂热者之夜》的完整规则引擎 + 网页客户端。
**三幕战役可在浏览器里连续游玩**：剧情阅读、场景间 XP 升级、战役结局、断点恢复、自由组卡、中文卡面全部就位。

## 功能一览

| 模块 | 内容 |
|---|---|
| 剧本 | 集结 / 午夜面具 / 深渊吞噬者，含幕与阴谋推进、地点行动、剧情分支与 R1/R2/R3 结局 |
| 战役层 | 战役日志、经验与升级、创伤、跨场景延续、故事资产、战役结局 |
| 卡池 | 基础包 **100 种玩家卡全部实现卡面效果**（含 L1–L5 升级版与基础弱点），全中文卡面 |
| 界面 | 可视化地点地图（防重叠布局）、卡图、点击查看任意卡牌详情、剧情阅读、起手重抽 |
| 组卡 | 五套起始牌组 + **自由组卡编辑器**（组卡规则校验） |
| 恢复 | 操作日志重放：服务重启后刷新页面自动回到中断局面 |
| 自动退出 | 关闭页面后服务自动清理，不占后台 |

## 快速开始

```powershell
python -m ahlcg.web.app            # 在项目根目录执行
python run.py                      # 或在任意目录执行这个
```

浏览器打开 **http://127.0.0.1:8765**。参数：`--port 9000` 换端口；`--auto-close 0` 关闭自动退出；
卡图默认从 ArkhamDB 按需下载并缓存到 `assets/cards/`，`--no-images` 可禁用。

首次启动会下载你用到的卡图（每张约 200KB），需要能访问 arkhamdb.com；下载失败自动回落文字卡面。

## 界面说明

- **左栏**：调查员（立绘 + 生命/理智/资源/线索/行动）、支援区、威胁区（缩略卡）、敌人
- **中栏**：**地点地图**（以你所在位置为中心分层展开，连线表示连通，节点带地点卡图）、选择行动、手牌
- **右栏**：幕卡/阴谋卡（叙事 + 目标 + 进度条）、混沌袋、日志
- **点击任意卡**（支援区、威胁区、手牌、敌人、地图节点、调查员立绘）弹出大图与完整中文文本
- 顶栏「剧情」按钮随时回读本幕开场故事；结算画面显示**结局正文**与战役日志
- 选择流程：**先点选选项 → 按确定**；可放弃的选择有「取消」

## 断点恢复

对局以"种子 + 操作序列"确定性重放。每次选择/升级/推进场景都会记入
`assets/sessions/<会话号>.json`；服务重启后，浏览器凭保存的会话号访问即自动重放恢复到中断局面。
刷新页面不会丢局，同一局可以跨多次启动玩完。

## 自动退出（不会一直占后台）

页面每 5 秒发一次心跳（`POST /api/ping`），关闭时发 `POST /api/bye`：

- 关闭页面约 8 秒后服务自动退出（含刷新宽限，刷新不会误杀）
- 兜底阈值 120 秒（容忍后台标签页定时器节流；页面重新可见会立刻补心跳）
- `--auto-close 300` 调长；`--auto-close 0` 关闭该行为

## 自由组卡

开始界面的「使用自由组卡」勾选后进入编辑器：按职业筛选基础包全部可用卡，
±选卡（同名限 2），凑满 30 张标准卡。专属卡与一张随机基础弱点自动加入；
服务端按完整组卡规则校验，非法时返回中文错误。

## 出问题先跑自检

```powershell
python tools/doctor.py
```

九组检查：Python/依赖/数据文件/卡池与卡面行为/五套起始牌组/机器人跑一局/剧本注册表/
战役与 Web 层/前端 HTTP 接口/前端 JS 语法。

### 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示"已有一个实例在运行" | 上次的服务还在 | 直接打开打印的网址；或 `--port 9000` 再开一个 |
| 端口被其它程序占用 | — | 启动器自动换下一个端口 |
| `ModuleNotFoundError: No module named 'ahlcg'` | 工作目录不对 | `cd` 到项目根目录，或用 `python run.py` |
| 关掉终端后端口仍被占用 | 强杀外层进程时 Python 子进程残留 | `Get-NetTCPConnection -LocalPort 8765 -State Listen` 找 pid，再 `Stop-Process -Id <pid>` |
| 提交选择提示"已过期" | 界面落后于服务器状态 | 现在会自动刷新重试；若仍出现请反馈 |

## 已知限制

- 单人单调查员设计；多人同局未实现
- 机器人（测试用自动决策器）很弱，三幕都会输——胜负请以真人游玩为准
- 个别极边缘规则未实现（如霰弹枪失败分支在单人下无从触发）
